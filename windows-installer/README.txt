AURELIA OS - Legacy Alpha
=========================

This is the legacy AURELIA kernel, packaged as a virtual machine.
It is a real bootable OS, but it is not the Ubuntu 26.04 + KDE release.

Sign in
-------

User:     aurelia
Password: solstice

Controls
--------

- Close the QEMU window to stop AURELIA OS.
- The desktop, dock, launcher, clock, settings, terminal, notes, files and
  other built-in applications are available.
- There is no network, no persistence, no disk installation and no package
  manager. Files and settings are lost when the VM stops.

Why a virtual machine?
----------------------

The current Ubuntu/KDE AURELIA ISO has not been built or boot-tested yet, so it
would be dishonest to label it as a working release. This installer gives you
the verified AURELIA kernel now, in an isolated VM, without changing Windows.

Removing it
-----------

Delete the AURELIA OS folder and the desktop/Start Menu shortcuts. Nothing is
installed system-wide.
